# Algorand Indexer

This helm chart allows you to run an Algorand indexer in a k8s cluster easily. It deploys a postgres database, a follower node, conduit and the indexer API (with optional ingress).

Check out the source at [AlgorandNodes github repository](https://github.com/scholtz/AlgorandNodes/tree/main/helm).

See [Default values](https://github.com/scholtz/AlgorandNodes/blob/main/helm/algorand-indexer/values.yaml) for the helm chart.
